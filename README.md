# حفظ القرآن

تطبيق أندرويد بسيط لتحفيظ القرآن الكريم لكبار السن: خط كبير وواضح، وخيارات قليلة.

- جدول السور: مربعات كبيرة، ويمكن إضافة السور أو إزالتها.
- تظهر آية واحدة فقط على الشاشة بخط ثابت، وتتلوّن الكلمة التي يقرؤها القارئ، والآية الطويلة تتحرك مع التلاوة.
- شريط يوضح التقدم في السورة.
- تكرار كل آية: مرة واحدة أو ٣ مرات.
- ١٢ قارئًا، منهم الحصري المعلّم والمنشاوي وعبدالباسط والعفاسي. التلاوة تعمل بالإنترنت، ويمكن تحميل أي سورة من داخل التطبيق للاستماع لها بدون إنترنت.
- نص الآيات من مصحف المدينة النبوية (مجمع الملك فهد لطباعة المصحف الشريف) بخطه العثماني.

## التحميل

كل تحديث على الفرع `main` يبني ملف `quran-hifz.apk` تلقائيًا وينشره في صفحة Releases باسم "latest".

## البناء يدويًا

يحتاج Android SDK و Gradle 8.9 و Java 17:

```
gradle assembleDebug
```
